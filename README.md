# GeoParquet Viewer

A simple GeoParquet Viewer for the Web.

## Development

```sh
npm install
npm run load-extensions
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
